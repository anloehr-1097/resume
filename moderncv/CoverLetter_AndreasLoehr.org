*** NOTE on the class key
This file registers =moderncvletter=, not =moderncv=, even though the
preamble is the same minus the bibliography and the =cvblock= environment.
=add-to-list= does *not* replace an entry whose car already exists, so if the
letter reused the key =moderncv= then whichever of the two files was
evaluated first in an Emacs session would silently supply the preamble for
both. Distinct keys make the export order irrelevant. Keep the shared part
of the two preambles in sync by hand when you change the style or colours.

*** NOTE on the letter API
moderncv 2.x needs no =letter= environment: =\makelettertitle= and
=\makeletterclosing= are used bare inside =document=, with =\recipient=,
=\opening=, =\closing= and =\enclosure= set beforehand. If your TeX Live is
old enough to ship moderncv 1.x, wrap the body in
=\begin{letter}{}= ... =\end{letter}=.

The sender block comes from the same commands as the CV header
(=\name=, =\address=, =\phone=, =\email=, =\social=), so those are repeated
below rather than shared.

Unlike the CV, the letter body needs no export blocks: it is flowing prose,
not two-column rows, so plain org paragraphs, =*bold*=, =/italic/= and lists
all export correctly.

*** NOTE on language
The scaffold below is English. For a German application, swap:

| English                   | German                          |
|---------------------------+---------------------------------|
| =\opening{Dear Sir or Madam,}= | =\opening{Sehr geehrte Damen und Herren,}= |
| =\closing{Yours faithfully,}=  | =\closing{Mit freundlichen Grüßen,}=       |
| =\enclosure[Enclosures]{...}=  | =\enclosure[Anlagen]{Lebenslauf, Zeugnisse}= |

and uncomment the =babel= / =\enclname= lines in the LaTeX Config block above.
