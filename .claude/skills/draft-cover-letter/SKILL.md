# What I do

Use this skill when creating a cover or motivation letter for a specific job.
Use the template in @CoverLetter_AndreasLoehr.org

Process:
1. Read the job description and identify the strongest reasons the role fits the applicant.
2. Select concrete experiences from the source CV that maps directly to the role.
3. Write in the language requested by the application.
4. Keep the letter short, direct, and specific.
5. Mention gaps honestly when the role asks for experience that is not directly supported.
6. End with a clear interest in discussing the role further.

Structure:
- Opening: state the role and why it is a strong fit.
- Middle: connect concrete experience to the job requirements.
- Closing: restate interest and keep the tone professional.

Rules:
- Do not repeat the CV line by line.
- Do not claim unsupported expertise.
- Do not over-explain; a focused letter is better than a long one.

Output:
- Save the letter as an Org file in the same job folder as the CV.
- Keep the file ready for export alongside the CV source.

# When to use me
Use this skill when asked to draft a cover letter for a position.
