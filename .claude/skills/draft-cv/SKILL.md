## What I do
Use this skill when extending an existing CV template in `Templates` into a job-specific CV, potentially extending the result CV based on data from `CV_Andreas_Loehr.md`.

Process:
1. Read the job description first and extract required skills, responsibilities, and keywords.
2. Choose which of the CV templates is most appropriate for the job. Copy this CV to the job specific folder.
3. Reorder sections so the most relevant experience appears first.
4. Rewrite project summaries to match the target role, but keep every claim grounded in the source material, esp. the `CV_Andreas_Loehr.md`
5. Add or remove project entries only when they are supported by the source CV or direct repository evidence.
6. Keep the tone concise and factual.

Rules:
- Do not invent domain experience, certifications, or tools.
- Do not upgrade tentative experience into expert claims.
- If a project is active, say so only when the repository or notes support that status.
- Prefer role-relevant wording such as "implemented", "built", "refactored", and "integrated" over vague phrasing.

Output:
- Save the adapted CV as an org file named `CV_AndreasLoehr.org` in the folder for this specific job posting.
- Preserve the existing template structure unless the job requires a minimal, evidence-based change.

## When to use me
Use this skill when asked to create a CV for a job or when asked to adjust a CV for a job.
